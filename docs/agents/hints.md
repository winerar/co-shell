# Обучение новичка: «Первые шаги» и подсказки

Решение владельца 2026-11-18 (#513): простое и ненавязчивое обучение для тех, кто **ни разу не вёл бюджет, но хочет начать**.
Цель — привить любовь к бюджету: человеку должно быть тепло и понятно, а не «правильно». Макеты — `docs/design/`.

## Золотое правило: подсказки живут вместе с интерфейсом
Поменял экран, шаг, жест, название или подпись — **в том же изменении** обнови подсказки и «Первые шаги»: текст, условие показа,
`HintId`, все языки `AppLanguage.SUPPORTED` (до публикации — русский, `glossary.md` §«Языки»). Подсказка, которая врёт про интерфейс, хуже её отсутствия.
- Переименовал раздел/кнопку → найди в `strings_hints.xml` упоминания пути («Ещё → …») и поправь.
- Убрал или перенёс жест/экран → убери подсказку (ID остаётся в `HintId.retired`, чтобы «уже показано» не ожило).
- Новая функция, которую новичок не поймёт без слова → новая подсказка (по таблице ниже) и строка здесь.
- Конец сессии: «менял вид/подпись/жест — менял ли подсказки?» (рядом с вопросом про доску, `workflow.md`).

## Тон
- Без вины и давления: нет красного, нет «вы не…», нет серий «N дней подряд». Любой шаг можно пропустить.
- Маленькие победы; термин объясняем в первую встречу одной фразой обычными словами.
- «Лимит — ориентир, а не запрет». Общие правила — `texts.md`, слова — `glossary.md`. Wallet и импорт не упоминаем (формат один).

## «Первые шаги» (вид А2: строка на «Обзоре» → шторка со списком)
Галочки ставятся **по данным**, а не по нажатию; сделаны первые три шага — строки нет (у действующих пользователей с лимитом её не видно). Последний шаг (семья) — необязательный.
| Шаг | Подпись | Отмечается |
|---|---|---|
| Добавьте счёт | Где лежат ваши деньги: карта, наличные или копилка. Начните с одного. | есть живой счёт |
| Запишите первую трату | Любую, хоть кофе. Нажмите «+». | есть операция |
| Задайте первый лимит | Сколько готовы тратить на продукты за месяц. Цифру можно менять. | есть лимит |
| Позовите близкого человека | Вместе проще. Можно и позже. | есть участник семьи |
- Строка: «Первые шаги» + «Сделано: 2 из 4 · Дальше: …»; на нуле — «Начнём со счёта». Шторка: «Скрыть шаги». Финал (один раз,
  `CoShellSuccessBurst`): «Всё готово. Вы уже ведёте бюджет — а это самое трудное.»
- «Отчёты» шагом не делаем: при первом заходе — подсказка `reports`. Задумано и **не сделано**: точка «есть новое» при 5–7 записях и пустой экран
  «Данных пока мало…» (проверка 2026-11-25).

## Вид: все подсказки — карточкой в экране (опрос 2026-11-25 «А», доски `Tip513*`)
Одна карточка `HintCard` (`CoShellCoachCard`: лампочка, текст обычным цветом, «Понятно», у моментов с экраном — «Открыть»). Сама не исчезает — успевают прочитать;
«Понятно» — навсегда. Слова — под шапкой своего экрана (`WordHint`); жесты, моменты и «Подсказки включены» — первой карточкой списка текущей вкладки (`HintSlot`
на «Обзоре», «Операциях», «Отчётах», «Ещё»); пойманная вне вкладок ждёт их. Над нижней панелью подсказок нет; над шторкой ввода — та же карточка (`SheetCoach`).

## Тёплые моменты (карточка вверху вкладки, один раз)
У `backup`, `month_end`, `theme` перед «Понятно» — «Открыть» на названный экран. Доски `Hint513Moment`, `Hint513MomentLong`.
| ID | Когда | Текст |
|---|---|---|
| `first_entry` | первая операция | Первая запись есть. Так и начинается бюджет. (вибрация `Confirm`, как у сохранения) |
| `first_limit` | первый лимит | Лимит задан. Теперь видно, сколько осталось. |
| `first_week` | 7 дней с записями | Неделя записей. Порядок в деньгах начинается с этого. |
| `welcome_back` | открыли после 3 дней без записей | С возвращением. Можно записать траты за эти дни: дата выбирается в операции. |
| `month_end` | конец месяца (+ точка на «Отчётах») | Месяц закончился. Посмотрите итоги. «Открыть» → «Итоги» прошлого месяца (#554, истории) |
| `limit_80` | 80 % лимита (строка на карточке, обычный цвет) | Продукты: ещё можно 90 USD. Подробнее — в «Бюджетах». |
| `backup` | 30 операций или 2 недели | Записей уже много. Сохраните резервную копию, чтобы ничего не потерять: Ещё → Резервная копия. |
| `theme` | 3 дня после начала | Приложение можно сделать своим: Ещё → Настройки → Внешний вид. |
| `pin_forgot` (#602) | PIN только что включён («Ещё → Конфиденциальность») | PIN включён. Забудете — на экране входа нажмите «Забыли PIN?». |
| `currency_account` | сохранён новый счёт не в валютах итогов (опрос 2026-11-19: плашка, не строка — шторка счёта без прокрутки) | Деньги в другой валюте? В итоги они войдут по курсу, он подставится сам. |

## Когда показывать (правила `HintPlanner`)
- Не больше **одной** подсказки за заход и **одной в день** (слова и жесты; **тёплые моменты вне лимита** — показываются по событию, один раз каждый, опрос 2026-11-19); несколько подходящих — первая по порядку таблиц (шаги → слова → жесты → моменты).
- **Пустой экран — исключение** (владелец 2026-11-25): если на экране ещё нет данных (новый человек), его подсказка-слово показывается, даже если сегодня
  уже была другая, и дневной лимит не тратит (`WordHint(emptyScreen)`): «Обзор» без операций, «Счета», «Долги», «Регулярные» без записей (над заглушкой),
  «Бюджеты» без лимитов, «Отчёты» без данных, «Цели» без целей, «Семья» до входа. Один раз и только при включённых подсказках — как обычно.
- Не раньше первого действия человека, не поверх шторок, не в первые секунды после запуска. Каждая — один раз, «✕»/«Понятно» = показано.
- Карточки вкладки — по одной: пришедшая, пока другая на экране, ждёт в очереди `HintCenter` (не теряется). Момент, пойманный на внутреннем экране
  («Бюджеты», «Конфиденциальность», шторка счёта), появится на вкладке. «День» — по часам телефона, не UTC.
- Состояние «включены / шаги скрыты» — одно на приложение (`HintCenter.enabled`, `stepsHidden`; до чтения — `null`, строка не мелькает); «Настройки» —
  `HintsSettingsViewModel`, моменты запуска проверяются раз за процесс (`takeLaunchMoments`), что бы ни открылось первым (проверка 2026-11-25).
- Только внутри приложения, без уведомлений. Основной поток — первые две недели; позже только события (`backup`, `month_end`, `limit_80`).
- «Показано» и «подсказки выключены» — **на устройстве** (как `ThemeSettings`), не синк, не Room, не резервная копия.
- Слова «возвращения» — без упрёка («с возвращением», не «давно не заходили»); у лимита — ни «превышен», ни красного до самого превышения.

## Знакомство с приложением (#598, опрос 2026-11-25 «А», доски `Tour598*`)
- Шесть историй (`hints/TourStories.kt`, экран — общий `StoriesScreen` с «Что нового», «Шаг N из 6», последняя кнопка «Начать»): счёт → запись трат →
  категории → лимиты → отчёты и итоги → семья и резервная копия; в каждой — путь к экрану. Переименовал экран или пункт меню — поправь и текст истории.
- Карточка «Знакомство с приложением» вверху «Обзора» (`TourCard`, `HintCenter.tour`): только новая установка (телефон с данными в день появления
  знакомства её не получает — `HintStore.tourChecked`, переживает сброс), подсказки включены, «Смотреть»/«✕» — убрать (ключ `tour_card`).
  **После «Показать подсказки заново» — снова** (правка владельца). Пересмотреть — «Ещё → Настройки → Помощь → Знакомство с приложением».

## Настройка: «Ещё → Настройки → Помощь»
- «Подсказки» — переключатель («Показываются» / «Выключены»), под ним кнопка-контур «Показать подсказки заново» (действие, не переход — #598 «Б», доска `Help598B`):
  без подтверждения, плашка «Подсказки включены». Сброс очищает «показано», снимает «скрыто» у шагов и возвращает карточку знакомства.
  Второй карточкой: «Знакомство с приложением», «Код приглашения», «Политика конфиденциальности».
