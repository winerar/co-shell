# Заметки агента

Факты, которые агент выяснил сам и которые экономят время следующей сессии: замеры, грабли,
приёмы. Не правила (они — в тематических файлах) и не история решений (ARCHITECTURE).
Пополнять в конце сессии; устаревшее — удалять. Файл ≤ ~120 строк: разросся — вынести тему
(уже вынесены: `notes-sync.md`, `notes-screenshots.md`, `notes-build.md`).
Формат: `- (дата) факт — что из этого следует`.

## Служебные скрипты
Таблица команд и флоу — `docs/agents/scripts.md` (`scripts/agent/agent.sh` без аргументов — список).
- (11-13) `origin/main` получает коммиты не через `dev` — «свои» = не в `dev` по патчу и не в `main`; ~70 веток: `merge-base` на каждый коммит давал 27 с, `comm` с одним `rev-list` + отсев по дате — 3 с.
