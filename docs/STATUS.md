## Где мы
- Модули: `app`, `core:model`, `core:domain`, `core:data`, `core:designsystem` (структура — `docs/agents/project-structure.md`).
- `core:domain`: `SaveTransactionUseCase`, `SaveAccountUseCase` (валюта счёта с операциями заблокирована),
  `SaveCategoryUseCase` / `ArchiveCategoryUseCase` (папки: один уровень, тип папки = тип подкатегорий),
  `DeleteAccount/CategoryUseCase` (используемое не удаляется — только архив), `SeedDefaultCategoriesUseCase`.
- `core:model`/`core:domain` курсы: `Rate` (точный курс), `ExchangeRate`, `rates/RateBook` + `CurrencyConverter`
  (правила поиска — `money-and-currency.md`); загрузка — `RatesProvider` перебирает источники
  (`core:data/rates/`: currency-api через jsDelivr → то же через Cloudflare → open.er-api, только последний курс).
  Готов в DI, но ещё никто не вызывает: нет хранения, фоновой загрузки и UI. Живьём API не проверялись
  (песочница их блокирует) — формат ответов взят из документации, проверить при первой загрузке на телефоне.
- `core:data`: Room (схема v1), мягкое удаление, баланс SQL-агрегатом, JSON-бэкап. Правила — `docs/agents/database.md`.
- `app`: навигация (type-safe routes, `navigation/`) с нижней панелью **Обзор · Операции · Счета · Ещё**.
  - Счета: список с балансами и архивом, редактор (название, валюта с подсказками, тип, начальный баланс), архив/удаление.
  - Ещё → Категории: вкладки Расходы/Доходы, раскрывающиеся папки, «Новая папка» (отметить категории внутрь),
    «Добавить в папку», редактор (название, тип, иконка, цвет, папка), архив/удаление.
    Значок категории (иконка в круге её цвета) — в списке категорий, в списке операций и в чипах
    выбора категории при вводе операции (общий компонент `CategoryBadge`, 38 иконок, 18 цветов).
  - Ввод операции (`transactions/edit/` — образец структуры экрана): Расход/Доход/Перевод, сумма,
    счёт (по умолчанию — последний использованный), категории с папками, дата (Сегодня/Вчера/DatePicker),
    заметка; перевод между валютами — вторая сумма. «Чек в другой валюте» (расход/доход): валюта и сумма
    чека + «списано со счёта», подсказка «Курс покупки: 1 USD = 1 049,69 ARS»; в списке — сумма чека
    под суммой операции (`ReceiptForm.kt`, `components/ReceiptSection.kt`). **Не проверено на телефоне.** Редактирование и удаление (маршрут с `transactionId`).
    Вход — FAB на «Обзоре» (если есть счета) и «Операциях».
  - «Операции» (`transactions/list/`): список по дням (липкие заголовки «Сегодня/Вчера/дата»), категория,
    счёт · заметка, сумма цветом; у перевода «A → B» и вторая сумма между валютами. Тап — редактор.
    Грузится весь список сразу — при импорте Wallet (тысячи строк) понадобится пагинация.
  - Ещё → Обновление приложения (`update/`): версия, проверка, «Скачать и установить» с прогрессом,
    запрос разрешения на установку; при запуске — диалоги «Доступна версия…» и «Что нового» (`update/startup/`).
  - Ещё → Резервная копия (`backup/`): «Сохранить копию» (системный диалог «Сохранить как»,
    имя `co-shell-<дата>.json`) и «Восстановить из копии» (выбор файла → подтверждение → итог).
  - Встряхивание → ввод операции (`shake/`, `core:domain/shake/ShakeDetector`): только на вкладках
    нижней панели и пока приложение на экране; короткая вибрация; выключатель «Ещё → Встряхнуть — новая
    операция» (по умолчанию включён). **Не проверено на телефоне** — порог 2.7g может потребовать подстройки.
  - Ещё → Обратная связь (`feedback/`): текст → Firestore `feedback` (REST, без SDK) + версия, телефон,
    Android, id установки. `feedback.yml` раз в 6 ч делает из новых сообщений issue с меткой `feedback`.
    Настройка Firebase сделана владельцем, выпущено в сборке 38, проверено владельцем.
