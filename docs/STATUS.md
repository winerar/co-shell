## Где мы
- Модули: `app`, `core:model`, `core:domain`, `core:data`, `core:designsystem` (структура — `docs/agents/project-structure.md`).
- `core:domain`: `SaveTransactionUseCase`, `SaveAccountUseCase` (валюта счёта с операциями заблокирована),
  `SaveCategoryUseCase` / `ArchiveCategoryUseCase` (папки: один уровень, тип папки = тип подкатегорий),
  `DeleteAccount/CategoryUseCase` (используемое не удаляется — только архив), `SeedDefaultCategoriesUseCase`.
- `core:data`: Room (схема v1), мягкое удаление, баланс SQL-агрегатом, JSON-бэкап. Правила — `docs/agents/database.md`.
- `app`: навигация (type-safe routes, `navigation/`) с нижней панелью **Обзор · Операции · Счета · Ещё**.
  - Счета: список с балансами и архивом, редактор (название, валюта с подсказками, тип, начальный баланс), архив/удаление.
  - Ещё → Категории: вкладки Расходы/Доходы, раскрывающиеся папки, «Новая папка» (отметить категории внутрь),
    «Добавить в папку», редактор (название, тип, папка), архив/удаление.
  - Ввод операции (`transactions/edit/` — образец структуры экрана): Расход/Доход/Перевод, сумма,
    счёт (по умолчанию — последний использованный), категории с папками, дата (Сегодня/Вчера/DatePicker),
    заметка; перевод между валютами — вторая сумма. Редактирование и удаление (маршрут с `transactionId`).
    Вход — FAB на «Обзоре» (если есть счета) и «Операциях».
  - «Операции» — пока заглушка с FAB, списка нет.
- Иконки: Material Symbols Outlined weight 300 (правила и скрипт — `code-style.md` §«Иконки»).
- Тесты: всего 85 — всё зелёное; `check assembleDebug` проходит.
- Структура кода: маленькие файлы по теме (`project-structure.md` §«Файлы»). Старые экраны
  `AccountEditScreen`, `CategoryEditScreen`, `CategoriesScreen` (~240–300 строк) ещё не разбиты.
- Приложение **всё ещё ни разу не запускалось** на телефоне/эмуляторе (в облаке нет эмулятора).
