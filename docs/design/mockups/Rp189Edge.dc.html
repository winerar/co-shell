Особые случаи

Месяц не законченНоябрь ещё идёт: остаток +820 — «пока». Норма сбережений — по закрытым месяцам.
Сентябрь: пришло 1 300, ушло 1 410 — остаток −110. Красным, без упрёков: «потратили больше, чем пришло».
Без курсаКапитал в USD по курсу на конец месяца. Нет курса для AMD — счёт без учёта, строкой «без учёта: AMD».
Операции из Wallet без автора — строкой «Из Wallet · 1 240» под участниками; переводы и «Корректировка баланса» — не траты и не доход.

История короче двух месяцев — столбцы за сколько есть, без «в среднем». Один участник — карточки «Кто сколько» нет.

TalkBack: «Октябрь: пришло 1 620, ушло 1 350, остаток плюс 270 долларов, отложили 17 процентов».
