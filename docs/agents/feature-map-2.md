Экрана и загрузки дополнения из приложения пока нет (этап 2, ждёт доски).
Экран «ИИ на телефоне» (#587, этап 2, опрос 2026-11-21 — все «А»; доски `AiOff`, `AiStep1`, `AiStep2`, `AiOn`, `AiData`): «Ещё → Настройки → Умные функции» (`SmartCard`, `Set1Root`) → `ai/AiAddonScreen` (карточка-герой со состоянием и полосой, факты / шаги / «Где работает», внизу «Включить · 2,5 ГБ» / «Отменить» / «Удалить модель», вопрос «Скачать 2,5 ГБ?» всегда). `AiAddonController` (один на процесс, `di/AiModule`): шаг 1 — файл дополнения из `…/releases/download/ai-addon/version.json` (`ReleaseAddonPackage`, свой каталог кэша `ai-addon`), системная установка `ApkInstaller.install(file, packageName)`, ожидание, пока дополнение не ответит (или Android сообщит об отмене); шаг 2 — `AddonControl.downloadModel()`; ошибки — `AiAddonProblem` (текст «что сделать»). Связь — `AddonBinder` (одна беседа: привязка → запрос → ответы → отвязка). Тесты: `AiAddonControllerTest`, эталоны `ai_addon*`. Публикация — `ai-addon-release.yml` (тег `ai-addon` в `co-shell-releases`, запускается вручную после релиза; пока не запущена — шаг 1 говорит «Дополнение пока недоступно»). **Не проверено на телефоне:** установка дополнения из приложения, связь, загрузка модели.
ИИ на телефоне, ответы опроса «открытые вопросы» (2026-11-21): слабый телефон (< 5600 МБ по `DeviceMemory`, это «6 ГБ» по данным ОС) — стадия `UNSUPPORTED`: карточка «Этому телефону не подойдёт», без кнопки (доска `AiWeak`); загрузка при закрытом приложении — `ai/AiDownloadService` (служба переднего плана `dataSync`, уведомление «Скачиваю ИИ · 42 %» + «Отменить», стартует из `AiAddonController.enable()` через `keepAlive`, сама останавливается); заметки без суммы → «Черновики» с пометкой «Нужна сумма», счёт по слову, иначе последний — для этапа 3 (быстрые заметки ещё не сделаны: нужны хранилище черновиков, экран заметок, строка на «Обзоре»).
