# Чеки: форматы, «Поделиться», образцы

Как приложение читает чеки из разных источников и как добавить новый формат (владелец 2026-11-20: «форматов QR, ссылок и документов
будет много — работа с ними оптимальная и удобная»). Сканер камеры — #526 (`receipt/scan/`), запись в БД — `database-tables.md` §«Чеки по QR».

## Конвейер: любой источник → текст → формат → шторка
| Источник | Где | Что становится текстом |
|---|---|---|
| Камера (QR) | `receipt/scan/` | содержимое QR |
| Ссылка из сканера/камеры (`ACTION_VIEW`) | `receipt/inbox/Incoming` | ссылка (берётся, только если её читает формат) |
| «Поделиться» текстом (`ACTION_SEND text/plain`) | `Incoming` | текст как есть (до `ReceiptFormats.MAX_TEXT`) |
| «Поделиться» PDF (Telegram-боты магазинов) | `receipt/inbox/ReceiptFileReader` | текстовый слой (`receipt/document/PdfText`, своя читалка без библиотек) → не узнан — QR первых 2 страниц (`PdfRenderer` + ZXing) |
| «Поделиться» фото/скриншот | `ReceiptFileReader` | QR на картинке (`QrInImage`, ≤ 2000 px) |
- Текст читает `core:domain/receipts/ReceiptFormats.read` — первый формат, который узнал, даёт `Receipt` (итог, дата, продавец, ключ, товары).
  Шторка ввода заполняется одинаково для всех (`transactions/edit/ReceiptEntry.withReceipt`); строка-источник: QR — «Из QR чека · продавец …», остальное — «Из чека · …».
- Товары чека → «Заметка» (если пустая): магазин первой строкой (её видно в списке), дальше «товар — сумма» по строке (`ReceiptNote`, до 1000 знаков); поиск находит операцию по товару.
- Ничего не узнано (#561, опрос «А») → пустая шторка с окном «Не удалось прочитать чек»: «✦ Прочитать с ИИ», если модель есть (#593, `ReceiptAi`, итог — только напечатанный в чеке; `cloud-ai.md`), «Ввести вручную» или «Отправить образец» —
  отзыв «Формат чека» с уже приложенным файлом (текст — как `shared-text.txt`; `ReceiptSamples`, кэш `shared/`, 5 последних).
- Всё на телефоне, офлайн; ссылки не открываются.

## Новый формат — чек-лист
1. Образец без личных данных (адрес, телефон, имя, номер карты → выдуманные) — `docs/samples/receipts/<id>.txt` (текст, как его даёт `PdfText`; для QR — ссылка).
2. `core:domain/receipts/<Name>Format.kt` — `object : ReceiptFormat`: дешёвая проверка `contains(маркер)` до регулярок; `null`, если хоть одно
   обязательное поле (итог, дата покупки, номер) не найдено — не угадывать. `key` = `"<id>:<номер>"` и **не меняется** (лежит в `receipt_key`).
   Суммы — через `AmountInText`/`MoneyParser` (`$` в Аргентине — ARS), без `Double`.
3. Добавить в `ReceiptFormats.all` (порядок: узкие форматы раньше общих) + тест на образце: итог, дата, ключ, «чужой текст — `null`», «нет итога — `null`».
4. Новый тип файла (не PDF/картинка/текст) — `Incoming.isFile` + `<data android:mimeType>` в манифесте + ветка в `ReceiptFileReader`.

## Чек → свой счёт и переводы между своими (#577, #646, #578; опрос 2026-11-23 «А»)
- Банковский чек несёт цифры карты/счёта: `Receipt.debitDigits` (последние 4, `Account.digitsOf`). `ReceiptAccounts.find` берёт **единственный живой** счёт с такими `cardDigits`;
  нет такого или два — окно «Какой это счёт?» (`ReceiptAccountSheet`, `ChoiceSheet`): ответ записывает цифры в счёт (поле «Для чеков» в редакторе счёта).
- «Перевод между своими счетами» (`AmeriabankTransferFormat`, ключ `ameriabank-own:<время>:<откуда>:<куда>:<сумма>`) — `Receipt.transfer`: шторка открывается как «Перевод»
  (`withReceiptTransfer`), оба счёта — по цифрам (сначала спросит «откуда», потом «куда»); сумма зачисления — только если валюты разные. Расходом такой чек не записывается; `receiptKey` — и у перевода.
- Перевод по телефону/номеру (T-Bank) остаётся расходом: «свой» только тот, где оба счёта нашлись среди своих. Новому формату с цифрами — заполнить `debitDigits`.

## Образцы от людей: отзыв «Формат чека»
- Вложения отзыва (`FeedbackAttachment`, до 3 файлов, 3 МБ) уходят частями base64 в Firestore `feedback_files` (Storage на бесплатном плане нет);
  робот (`scripts/feedback_files.py`) склеивает их, кладёт в ветку `feedback-files` (`feedback/<id документа>/…`), ссылки — в задаче, части удаляет.
- Агенту: `git fetch origin feedback-files` → файл → анонимизировать → образец (шаг 1). Сам файл в `dev`/`main` не коммитить — там личные данные.
