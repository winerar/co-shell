# Облачный ИИ (Claude Haiku) — #635

Третий способ разбора рядом со словарём и «ИИ на телефоне» (`on-device-ai-plan.md`). Решение владельца 2026-11-22, `ARCHITECTURE.md` §«Принятые решения».

## Устройство
- `tools/ai-proxy/` — Cloudflare Worker (`worker.js`, тесты `node --test tools/ai-proxy/worker.test.mjs`, без зависимостей). Проверяет токен Firebase Auth
  (RS256 по JWKS Google, `aud`/`iss`/`exp`), считает запросы человека за день (KV `USAGE`, `DAILY_LIMIT`, по умолчанию 100), добавляет защитную фразу
  и зовёт `claude-haiku-5-5` (мышление выключено, `effort: low`, ответ ≤ 1024 токенов). Ключ Claude — только секрет `ANTHROPIC_API_KEY` Worker-а.
- `core:domain/ai/RoutedLanguageModel` — облако (если `CloudAiSettings.enabled` и оно доступно) → при любой неудаче модель на телефоне → `null` (правила).
  Пока переключатель выключен (по умолчанию), наружу не уходит ничего.
- `app/ai/cloud/CloudLanguageModel` — HTTP к Worker-у (`BuildConfig.AI_PROXY_URL`, репозиторная переменная CI; пусто → облако недоступно),
  `PrefsCloudAiSettings` — переключатель на устройстве (не синк, не копия). Подключено в `di/AiModule`: всё, что просит `LanguageModel`
  (сейчас `NoteHints` заметок), получает маршрутизатор. Новая функция с ИИ — тот же `LanguageModel`, облачный путь появляется сам.

## Правила
- Облако видит только текст заметки/чека и названия категорий и счетов (счёт — «Название · валюта · вид», без сумм и баланса) — не историю и не данные семьи. Суммы и даты из ответа не берём (`NoteHints`); ответ проверяет код.
- Всё с ИИ — «бета» (`ui/ai/BetaMark`), подпись источника — «предложено ИИ» ✦.
- Предел расходов — предоплаченный баланс API (~$5); счётчик в KV не атомарен (всплеск может чуть превысить лимит). Бесплатный KV — 1000 записей/сутки:
  для публичного запуска счётчик переезжает на Durable Objects (`monetization.md`).
- `play`-сборка: облако выключено (`play-release-plan.md`).

## Экран и состояние (2026-11-23)
Доски `CloudOff`/`CloudOn`/`CloudConsent`/`CloudNoLogin`/`CloudNotes`/`CloudBusy`/`CloudLimit` (опрос `poll-cloud-ai.json`, все «А»), код — `app/ai/cloud/` (`CloudAiScreen`, `CloudAiViewModel`),
строка «Облачный разбор» в «Умных функциях» (скрыта, если сборка без `AI_PROXY_URL`). Переключатель спрашивает «Включить облачный разбор?»; без входа в «Семью» он недоступен.
Остаток за день приходит от Worker-а (`left`/`limit`) и хранится на телефоне (`CloudQuota`, показывается только за свой день UTC). Лимит дня: `LanguageModel.limited` → `ProcessQuickNoteUseCase.Result.limited`
→ `CloudLimitNotice` → спокойная строка над «Черновиками». Подсказок (`hints.md`) экран не требует: он рассказывает о себе сам, как «ИИ на телефоне».
Ждёт владельца: развернуть Worker (`docs/setup/cloud-ai.md`, #674) и задать `AI_PROXY_URL`; до этого в приложении строки «Облачный разбор» нет.
Другие функции (умная категория #584, нечитаемые чеки #561, голос #585) — домен-код на `LanguageModel` пишется вместе с ними, отдельного клиента не нужно.

## Способ оплаты в заметках (2026-11-23)
Строка с бесплатной моделью (`LanguageModel.cheap`, у облака) целиком уходит в разбор вместе со списком счетов (`AccountLabels`): модель называет счёт, который строка
называет или подразумевает («мп», «с маминой», «долларами»), либо ничего. Порядок выбора счёта: слово названия счёта (правила) → счёт модели (только из списка; не противоречит
слову «карта»/«нал» и названной валюте) → валюта по порядку числа (ниже) → валюта страны/последний использованный. Слабая модель на телефоне получает по-прежнему только неясные строки. Текст согласия и
плашки в «Умных функциях»: «уходят текст заметки или чека и названия категорий и счетов».

## Валюта по порядку числа (2026-11-23)
Правило, без модели (`drafts/CurrencyGuess`, целые числа, без `Double`): если в строке нет валюты и счёт не назван, по числу знаков целой части выбирается валюта счетов,
у которой «обычная трата» ближе всего: медиана знаков прошлых расходов (от 3 штук), иначе грубая таблица `PRIOR` (USD 2, RUB 3, ARS 4…). «кофе 3500» — песо, «кофе 5» — доллары.
Ничья (400 — одинаково далеко) или одна валюта на счетах — прежний выбор (валюта страны, последний счёт). Названный счёт и написанная валюта сильнее. Число перечитывается в валюте счёта.

## Категория нового получателя (#594, 2026-11-23)
`core:domain/ai/PayeeCategoryAi` (+ `NoLanguageModel` для тестов): после истории и словаря брендов (`CategoryGuess`) шторка ввода новой траты спрашивает модель — текст продавца из QR
или заметки (от 3 букв, через 0,7 с после последней буквы) и названия категорий расходов; ответ вне списка — ничего. Ручной выбор сильнее и стирает метку; подпись «предложено ИИ» + искра + «бета»
(`AiGuessCaption`, поле `categoryByAi`, доска `EntryGuessAi`). Работает с любой моделью (облако, телефон).
