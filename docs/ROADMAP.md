# План разработки co-shell (черновик)

Итерации примерно по 1–2 недели. Каждая заканчивается рабочей сборкой.

## Этап 0. Фундамент
- [ ] Android-проект: Kotlin, Compose, Gradle version catalog, Hilt
- [ ] Базовая модульная структура, design system (тема, цвета, типографика)
- [ ] CI в GitHub Actions: lint + detekt + unit-тесты + debug APK
- [ ] Модель `Money` (Long minor units + валюта) с тестами форматирования

## Этап 1. Локальный MVP (один пользователь, без сети)
- [ ] Room: Account, Category, Transaction + миграции
- [ ] Набор категорий по умолчанию
- [ ] Экран ввода операции (быстрый: сумма → категория → сохранить, ≤ 3 тапа)
- [ ] Список операций с группировкой по дням, редактирование, удаление
- [ ] Счета и баланс по каждому, переводы между счетами
- [ ] Главный экран: остаток, траты за месяц

**Результат:** приложением уже можно пользоваться одному.

## Этап 2. Семья и синхронизация
- [ ] Выбор бэкенда (см. ARCHITECTURE §5), авторизация
- [ ] Создание семьи, приглашение по коду/ссылке, роли
- [ ] SyncEngine: очередь `pendingSync`, WorkManager, pull по `updatedAt`
- [ ] Tombstones, last-write-wins, тесты конфликтов
- [ ] Автор операции видно в списке; общие и личные счета
- [ ] Правила безопасности на сервере (доступ только членам семьи)

**Результат:** два телефона видят один бюджет, работает офлайн.

## Этап 3. Бюджеты и аналитика
- [ ] Месячные лимиты по категориям, прогресс-бары
- [ ] Отчёты: структура трат (донат), динамика по месяцам, по членам семьи
- [ ] Фильтры и поиск по операциям
- [ ] Уведомления о превышении лимита

## Этап 4. Удобства
- [ ] Регулярные платежи (подписки, коммуналка)
- [ ] Мультивалютность с курсами
- [ ] Экспорт/импорт CSV, резервная копия
- [ ] Виджет на рабочий стол для быстрого ввода
- [ ] Блокировка приложения (биометрия/PIN)
- [ ] Тёмная тема, локализация RU/EN

## Этап 5. Релиз
- [ ] Иконка, онбординг, политика конфиденциальности
- [ ] Release-подпись, R8, Crashlytics/аналог
- [ ] Закрытое тестирование в Google Play / RuStore

## Идеи на потом
- Распознавание чеков (QR с чека ФНС), импорт банковских выписок
- Цели накоплений («копилки»)
- Wear OS / iOS (через Kotlin Multiplatform — domain и data уже на чистом Kotlin)
