# Заметки агента

Факты, которые агент выяснил сам и которые экономят время следующей сессии: замеры, грабли,
приёмы. Не правила (они — в тематических файлах) и не история решений (ARCHITECTURE).
Пополнять в конце сессии; устаревшее — удалять. Файл ≤ ~120 строк: разросся — вынести тему.
Формат: `- (дата) факт — что из этого следует`.

## Служебные скрипты `scripts/agent/`
| Скрипт | Когда |
|---|---|
| **`agent.sh [команда]`** | **одна точка входа для всего ниже** (без аргументов — список команд по-русски); новый скрипт — сюда же |
| `gradle.sh <задачи>` | Gradle для агента вместо `./gradlew`: зеркало Maven Central (`maven-mirror.init.gradle`), при 429 — докачка curl-ом и повтор |
| `session-start.sh` | первая команда сессии: fetch, чужие невлитые ветки, перенос ветки на `origin/dev`, STATUS, доска задач |
| `tasks.sh [статус…]` | открытые задачи по колонкам (`gh api search/issues`); `tasks.sh next` — одна колонка |
| `check.sh` | перед коммитом (`check assembleDebug` через `gradle.sh`, краткий вывод); `--quick` — только unit-тесты |
| `session-end.sh` | перед финальным PR: незакоммиченное/незапушенное, дата и число тестов в STATUS, размеры файлов |
| `gen-wallet-export.py [строк]` | синтетическая выгрузка Wallet (по умолчанию 10 000 строк, переводы парами) — импорт на телефоне для замера (#131) |
| `gen-test-backup.py [-o файл]` | тестовый бэкап JSON с большим объёмом данных (~9 тыс. операций за 24 мес., `--months`, `--per-day`, `--seed`); проверен импортом |
| `sync-dev.sh` | влить `origin/dev` в ветку: «OK» или конфликтующие файлы с подсказками (STATUS, схемы Room) |
| `build-summary.sh [--ci] <лог>` | краткий отчёт сборки: ошибки, `Tests: N`, упавшие тесты с причиной, lint; его зовут `check.sh` и CI |
| `gen-flows-board.py [файл]` | перерисовать доску «Воркфлоу» из таблицы потоков в скрипте; потом `h` в `canvas.json` и публикация на холст |
| `gen-mockups.py` | пересобрать холст дизайна: доски состояний (`mockup_screens_*.py` из кирпичей `mockup_bricks.py`), «Тема макетов», «Настройки», «Предложения», «Воркфлоу»; перевести все доски на темы; записать `canvas.json` (ряды — `LAYOUT`) |
| `mockup_theme.py <доска>…` | перевести цвета доски (рисуем во «Вольт · тёмная») на токены темы; повторный запуск безопасен |
| `render-mockups.js <папка> dark\|light <палитра> <доски>…` | локальные PNG досок без холста (упрощённый рантайм: без событий и шрифтов) |
| `profile-build.sh [задачи]` | где тратится время сборки: самые долгие задачи, итог lint/тестов (~3–5 мин) |

Скрипты CI и для владельца остаются в `scripts/` (`feedback_to_issues.py`, `make-update-files.py`,
`material-symbol-to-vector.py`). Новый служебный скрипт — сюда же в таблицу.

## Грабли проекта
- (11-10) ViewModel, который в `init {}` запускает корутину, в тесте создавать `by lazy` (или в `@Before`): поле
  класса инициализируется раньше `MainDispatcherRule`, и `viewModelScope` молча не работает.
- (11-10) `Modifier.drawBehind` на `NavigationBar`/`Surface` рисует **под** их фоном — фон закрасит рисунок.
  Фон ставить своим `background()` перед `drawBehind`, а `containerColor = Transparent` (так пилюля вкладки).
- (11-10) Тест `Transaction` перевода: нужны `toAmount` и `toAccountId` ≠ `accountId` (проверки в `init`).
- (11-10) Ручной курс в `RateBook` действует до **следующего ручного** и бьёт скачанные на всех поздних датах —
  массово писать ручные курсы (импорт и т. п.) нельзя: последний такой курс заморозит пересчёт пары.
- (11-09) `rememberGraphicsLayer().record{}` хранит ссылки на слои детей, а не их копию — снимок «старого» кадра
  делать сразу `toImageBitmap()` до смены (так `motion/ThemeReveal.kt`), иначе дети перерисуются уже новыми.
- (11-09) Слияние нескольких веток: читать **весь** вывод `git merge` (не `tail`), перед коммитом —
  `git grep -n '^<<<<<<< '`; так маркер конфликта чуть не уехал в `ARCHITECTURE.md`.
- (11-09) `MaterialTheme(motionScheme = …)` и интерфейс `MotionScheme` в material3 **1.4.0 закрыты** (`internal`),
  в `1.5.0-rc01` открыты — поэтому версия material3 закреплена в `libs.versions.toml`; при выходе стабильной 1.5 — перейти на неё.
- (11-09) Пересечение касаний в Compose: родительский `detectTapGestures` получает тап по ребёнку, если тот не
  поглотил событие (`Surface` без `onClick` не поглощает) — скрим шторки сделан **соседом** под ней, а не родителем.
- (11-09) `AnimatedVisibility` внутри колонки с `spacedBy`: зазор появляется/исчезает рывком вместе с ребёнком —
  отступ класть внутрь раскрывашки, а её — в колонку, где всегда что-то видно (так в форме операции).
- (11-09) Lint `UnusedContentLambdaTargetStateParameter`: в `AnimatedContent` рисовать из параметра лямбды, а не из
  внешнего состояния; ключ анимации — `contentKey` (иначе уходящий кадр показывает уже новое состояние).
- (11-09) Облачные сессии создают ветки `ccr-*`/`claude/*`; сессия может закончиться, не открыв PR —
  `session-start.sh` показывает такие ветки (так нашёлся невлитый пункт (ж) в `ccr-08ccf27a-wf9rbo`).
- (11-09) `main` содержит только merge-коммиты релизов: «коммиты не в `dev`» считать с `--no-merges`.
- (11-09) Тест «пока следующая страница не пришла» нельзя писать на `UnconfinedTestDispatcher` — поток
  пересобирается синхронно; нужен обычный `runTest` + `runCurrent()` (так в `GrowingWindowTest`).
- (11-09) M3 красит `primary` и как заливку, и как текст (`TextButton`, фокус поля, `Tab`, «сегодня» в `DatePicker`).
  При светлом неоновом `primary` текстовые места переопределять на `accentInk()`, иначе текст исчезает на белом.
- (11-09) Firestore 429 (`Too Many Requests`) = исчерпана дневная квота Spark (50 тыс. чтений), а не частота.
  Опрос (тогда раз в 10 с, с 11-11 — раз в минуту): любое лишнее чтение × число опросов × 2 телефона. Курсор pull — строго после последней записи
  (`FirestoreRemoteStore.Position`); тест на «пустые опросы ничего не читают» — `SyncEngineTest`.
- (11-10) Аудит чтений Firestore: пустой `runQuery` всё равно = 1 чтение; одинокий участник читал ещё
  и документ семьи на каждом опросе (×2). Теперь `PollBackoff` (10 → 60 с) и проверка участников ≤ 1/мин.
  Остаётся: свои отправленные записи читаются обратно следующим pull (импорт 9 тыс. операций = 9 тыс.
  чтений на отправителе) — убрать можно только фильтром `updatedBy != я` с составным индексом.
- (11-10) Release падал «Top section of docs/whats-new.md is already released»: три PR (#90, #91, #94) влили
  заметные изменения без нового раздела. Теперь `session-end.sh` предупреждает, если верхний раздел совпадает
  с `main`, а ветка меняет `app/`/`core/`.
- (11-10) RTDB REST/SSE проверены в эмуляторе (`database`, порт 9000, `?ns=demo-coshell-default-rtdb`): поток шлёт
  `event: put` / `data: {"path":"/","data":…}` + пустая строка, первым — текущее значение узла (`null`, если пусто).
  Токен эмулятора Auth годится для `?auth=`; `Authorization: Bearer owner` — админ (засеять данные).
- (11-10) `m2-mirror.sh` с `M2_REPO` раньше перезаписывал `m2-init.gradle` путём к `~/.m2` → Gradle снова шёл в
  Maven Central и ловил 429. Теперь с `M2_REPO` init-скрипт не пишется.
- (11-10) Скриншот экрана для сверки с доской без эмулятора: временный тест Robolectric с
  `@GraphicsMode(GraphicsMode.Mode.NATIVE)`, `qualifiers = "w390dp-h844dp-xxhdpi"`, `MainShell` + экран на данных
  доски, `onRoot().captureToImage().asAndroidBitmap()` → PNG в scratchpad; тест не коммитить. Работает (~20 с).
- (11-10) `MainShellSmokeTest`: плашка обновления там не выровнена и лежит слева вверху поверх «✕»/«назад» шапки —
  клик по ним не доходит; выход из режима проверять `onBackPressedDispatcher.onBackPressed()`.
- (11-11) PR, влитый автослиянием (GITHUB_TOKEN), не закрыл задачу по `Fixes #156`, а закрытие тем же токеном не
  запускает `tasks.yml` — доска отстала. Теперь `automerge.sh` сам закрывает задачи из `Fixes`, снимает
  `status:*` и запускает синк доски; `session-end.sh` перечисляет задачи `status:in-progress`.
