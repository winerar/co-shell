# Деньги и валюты

## Хранение
- Сумма = `Money(amountMinor: Long, currency: CurrencyCode)`. Минимальные единицы: копейки, центы, сатоши.
- Число знаков после запятой — `Currencies.info(code).fractionDigits` (JPY 0, RUB 2, KWD 3, BTC 8).
  Неизвестный ISO-код → 2.
- В Room: две колонки `amount_minor INTEGER` + `currency TEXT`. В Firestore — так же (`Long` + строка).
- `Double`/`Float` для денег запрещены везде, включая промежуточные вычисления.

## Арифметика
- `+`, `-`, сравнение — только в одной валюте, иначе `IllegalArgumentException`.
- Переполнение → `ArithmeticException` (никакого тихого переноса).
- Деление/проценты/распределение (появятся позже) — отдельные функции с явным правилом остатка.

## Ввод и вывод
- Ввод пользователя → `MoneyParser.parse(text, currency)`: пробелы игнорируются, `,` и `.` распознаются
  как разделители, лишние знаки после запятой — ошибка `TOO_MANY_FRACTION_DIGITS`, а не округление.
- Вывод → `MoneyFormat` (`RU`: «1 234,56 ₽», `EN`: «$1,234.56»). Форматирование только в ViewModel/UI-слое.

## Мультивалютность (подробности — ARCHITECTURE §6)
- Факты хранятся в исходной валюте; конвертация — только при показе, по курсу на дату операции.
- Смена основной валюты не меняет данные, только представление.
- Курсы (этап 3) — `BigDecimal`-подобный KMP-тип, хранение строкой, округление HALF_EVEN при показе.
- Обмен валют — перевод между счетами с двумя суммами (`amountMinor` и `toAmountMinor`).
