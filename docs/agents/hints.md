# Обучение новичка: «Первые шаги» и подсказки

Решение владельца 2026-11-18 (#513): простое и ненавязчивое обучение для тех, кто **ни разу не вёл бюджет, но хочет начать**.
Цель — привить любовь к бюджету: человеку должно быть тепло и понятно, а не «правильно». Макеты — `docs/design/`.

## Золотое правило: подсказки живут вместе с интерфейсом
Поменял экран, шаг, жест, название или подпись — **в том же изменении** обнови подсказки и «Первые шаги»: текст, условие показа,
`HintId`, все языки `AppLanguage.SUPPORTED`. Подсказка, которая врёт про интерфейс, хуже её отсутствия.
- Переименовал раздел/кнопку → найди в `strings_hints.xml` упоминания пути («Ещё → …») и поправь.
- Убрал или перенёс жест/экран → убери подсказку (ID остаётся в `HintId.retired`, чтобы «уже показано» не ожило).
- Новая функция, которую новичок не поймёт без слова → новая подсказка (по таблице ниже) и строка здесь.
- Конец сессии: «менял вид/подпись/жест — менял ли подсказки?» (рядом с вопросом про доску, `workflow.md`).

## Тон
- Без вины и давления: нет красного, нет «вы не…», нет серий «N дней подряд». Любой шаг можно пропустить.
- Маленькие победы; термин объясняем в первую встречу одной фразой обычными словами.
- «Лимит — ориентир, а не запрет». Общие правила — `texts.md`, слова — `glossary.md`. Wallet и импорт не упоминаем (формат один).

## «Первые шаги» (вид А2: строка на «Обзоре» → шторка со списком)
Галочки ставятся **по данным**, а не по нажатию; у действующих пользователей всё отмечено, карточки нет. Пятый шаг — необязательный.
| Шаг | Подпись | Отмечается |
|---|---|---|
| Добавьте счёт | Где лежат ваши деньги: карта, наличные или копилка. Начните с одного. | есть живой счёт |
| Запишите первую трату | Любую, хоть кофе. Нажмите «+». | есть операция |
| Задайте первый лимит | Сколько готовы тратить на продукты за месяц. Цифру можно менять. | есть лимит |
| Позовите близкого человека | Вдвоём проще. Можно и позже. | есть участник семьи |
- Строка: «Первые шаги» + «Сделано: 2 из 4 · Дальше: …»; на нуле — «Начнём со счёта». Шторка: «Скрыть шаги». Финал (один раз,
  `CoShellSuccessBurst`): «Всё готово. Вы уже ведёте бюджет — а это самое трудное.»
- «Отчёты» шагом не делаем: при 5–7 записях на вкладке — точка «есть новое», при первом заходе подсказка; раньше — пустой экран
  «Данных пока мало. Запишите ещё несколько трат, и здесь появится картина.»

## Подсказки-слова (вид П1: строка под шапкой, `CoShellHint`, «✕»)
| ID | Где / когда | Текст |
|---|---|---|
| `overview_empty` | «Обзор» без операций | Операций пока нет. Нажмите «+», чтобы записать первую. |
| `accounts` | Счета | Счёт — место, где лежат деньги. Баланс считается сам. |
| `entry_minimal` | шторка ввода | Нужны только сумма и счёт. Остальное можно пропустить. |
| `keypad_math` | клавиатура суммы, первый раз | Можно складывать и вычитать: 300 + 150. |
| `entry_refund` | «Детали» шторки, первый раз | Вернули деньги? Отметьте «Это возврат». |
| `categories` | Категории | Категория — на что ушли деньги. Готовые подойдут, свои добавите потом. |
| `budgets` | Бюджеты | Лимит — сколько можно потратить на категорию за месяц. Это ориентир, а не запрет. |
| `reports` | Отчёты, первый заход | Здесь видно, на что уходят деньги. Чем больше записей, тем точнее картина. |
| `tags` | Теги; и при 10 операциях в «Операциях» | Тег — цветная метка операции, например «отпуск» или «подарки». |
| `family` | Семья | Вдвоём проще: записи с обоих телефонов собираются в одном месте. |
| `currency_account` | создан счёт в другой валюте | Деньги в другой валюте? Итоги посчитаются в валютах итогов, курс подставится сам. |
| `currency_receipt` | платёж в валюте не со счёта | Укажите сумму покупки, и курс посчитается сам. |

## Подсказки-жесты (вид П2: пузырь `CoShellPeekBubble`, кнопка «Понятно»)
| ID | Когда | Текст |
|---|---|---|
| `hold_select` | «Операции», есть ≥ 3 | Удерживайте операцию, чтобы выбрать несколько. |
| `swipe_tabs` | после 2-й смены вкладки кнопками | Листайте вбок, чтобы сменить вкладку. |
| `template` | три похожие траты подряд (категория + счёт) | Трата повторяется? Сохраните шаблон, и она внесётся в одно нажатие. |
| `edit_tap` | после первой операции | Ошиблись? Нажмите на операцию, чтобы поправить. |

## Тёплые моменты (плашка, один раз)
| ID | Когда | Текст |
|---|---|---|
| `first_entry` | первая операция | Первая запись есть. Так и начинается бюджет. (вибрация `Confirm`, как у сохранения) |
| `first_limit` | первый лимит | Лимит задан. Теперь видно, сколько осталось. |
| `first_week` | 7 дней с записями | Неделя записей. Порядок в деньгах начинается с этого. |
| `welcome_back` | открыли после 3 дней без записей | С возвращением. Можно записать траты за эти дни: дата выбирается в операции. |
| `month_end` | конец месяца (+ точка на «Отчётах») | Месяц закончился. Посмотрите итоги: Отчёты. |
| `limit_80` | 80 % лимита (строка на карточке, обычный цвет) | Продукты: ещё можно 90 USD. Заглядывайте в «Бюджеты», когда захотите. |
| `backup` | 30 операций или 2 недели | Записей уже много. Сохраните резервную копию, чтобы ничего не потерять: Ещё → Резервная копия. |
| `theme` | 3 дня после начала | Приложение можно сделать своим: Ещё → Внешний вид. |

## Когда показывать (правила `HintPlanner`)
- Не больше **одной** подсказки за заход и **одной в день**; несколько подходящих — первая по порядку таблиц (шаги → слова → жесты → моменты).
- Не раньше первого действия человека, не поверх шторок, не в первые секунды после запуска. Каждая — один раз, «✕»/«Понятно» = показано.
- Только внутри приложения, без уведомлений. Основной поток — первые две недели; позже только события (`backup`, `month_end`, `limit_80`).
- «Показано» и «подсказки выключены» — **на устройстве** (как `ThemeSettings`), не синк, не Room, не резервная копия.
- Слова «возвращения» — без упрёка («с возвращением», не «давно не заходили»); у лимита — ни «превышен», ни красного до самого превышения.

## Настройка: «Ещё → Приложение»
- «Подсказки» — переключатель («Показываются» / «Выключены»); «Показать подсказки заново» — «Вернёт «Первые шаги» и советы»,
  без подтверждения, плашка «Подсказки включены». Сброс очищает «показано» и снимает «скрыто» у шагов.

## Где в коде (план, #513)
- `core:domain/hints/`: `HintId`, `HintTrigger`, `HintPlanner` (чистая логика «что показать», тесты), `HintsSettings` (интерфейс);
  шаги — `FirstSteps` (`FirstStepsState` из данных). Хранение — `app/.../hints/` (настройки устройства).
- UI: `app/.../hints/` — блоки на утверждённых компонентах (`CoShellHint`, `CoShellPeekBubble`, `CoShellNoticePill`, шторка). Строки —
  `strings_hints.xml` на всех языках. Новый вид подсказки/плашки — сначала доска «Компоненты» (`components-approved.md`).
- Тесты: `HintPlannerTest` (порядок, лимиты, сброс), `HintsCoverageTest` — у каждого `HintId` есть строка во всех языках и запись в
  таблицах этого файла; убранный экран/жест — в `retired`.
