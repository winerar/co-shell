# Что нового (для пользователей)

Текст **верхнего** раздела показывается в приложении: в предложении обновиться и в окне
«Что нового» после установки. Пишите для семьи, по-русски, 1–5 пунктов, без технических деталей.
Текст **публичный** (уходит в релизы `co-shell-releases`) — без имён, сумм и банков.
Новый раздел — сверху, когда в `dev` попадает заметное пользователю изменение, если верхний раздел
уже выпущен (ушёл в `main`). При релизе показывается только верхний раздел — копите пункты в нём.
