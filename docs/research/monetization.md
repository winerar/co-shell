# Экономика и платные функции (черновик для обсуждения)

Начато 2026-11-23 (#636). Решения владельца: рынки — **Аргентина, Армения, РФ** (для РФ нужны другие способы оплаты); цель — **покрыть расходы на содержание и разработку и получить небольшой доход**; стартовая гипотеза — «бесплатное ядро + подписка на облачные функции». Детали ещё обсуждаются. Пометка **[сверить]** — проверить перед решением; юридические и налоговые вопросы — консультация, не мои выводы.

## 1. Что платное, что бесплатное (гипотеза)
- **Бесплатно** — всё без сервера: учёт, мультивалюта, отчёты, бюджеты, шаблоны, резервная копия вручную, «ИИ на телефоне».
- **Платно (подписка)** — то, у чего есть расход на пользователя: «Семья» (синк Firestore), облачный разбор заметок (API Claude, #635), облачная автокопия.
- **Возможно разово «Pro»** — удобства без сервера (виджеты, импорт выписок, ярлыки): решить по данным теста.
- Семья владельца — бесплатно (промокод / тестеры Play).

## 2. Каналы и оплата (решения владельца 2026-11-23)
- **Без российских сервисов:** RuStore и подобное не используем; не «пока», а решение. РФ-пользователи приходят через APK с сайта.
- **Два канала:**
  - **Google Play** — бесплатная урезанная, но качественная и удобная версия (flavor `play`): всё локальное, без платных функций, цен и призывов купить, без самообновления. Сайт — только как «сайт разработчика» и нейтральный пункт «Ещё → О приложении»; слов «полная версия» и ссылки на APK внутри приложения нет (риск политик Play: обход Play Billing, установка мимо Play — **[сверить в Play Console / политике платежей]**).
  - **APK с сайта (лендинг)** — полная версия, самообновление, платные функции по подписке.
- **Оплата подписки — через Telegram** (позже Telegram Mini App как личный кабинет и страница оплаты; бюджет остаётся в нативном приложении): бот на Cloudflare Worker принимает оплату, выдаёт лицензионный ключ, привязанный к Telegram-аккаунту; приложение проверяет ключ через Worker (`LicenseKey` в `Entitlements`, §3).
  - Для цифровых товаров Telegram требует Stars; вывод Stars — через TON/Fragment, доступность и сроки для владельца **[сверить]**. Вариант без Stars — оплата криптой (USDT/TON) через бота.
  - Для РФ — тот же путь (крипта/Stars), без российских платёжных сервисов.
- Налоги и выплаты (Аргентина/Армения) — бухгалтер; доступность посредников-«продавцов» (Paddle, Lemon Squeezy) — **[сверить]**.
- Подписка на «Семью» одна на семью (платит владелец), до 10 участников (#661); ключ и вход привязаны к Telegram-аккаунту (#662).
- Цены: в долларах (Stars/USDT), с поправкой на покупательную способность по странам.
- Play Billing (комиссия 15 %) — запасной вариант, если позже понадобится монетизация внутри Play; архитектура `Entitlements` его допускает.

## 3. Архитектура прав на функции
- `core:domain/entitlements/Entitlements` — «включена ли функция X»; источники: `LicenseKey` (Telegram, основной), `PlayBilling` (запасной). Остальной код про оплату не знает.
- Проверка покупок и ключей — Cloudflare Worker + KV (бесплатный план); состояние хранится на телефоне, работает офлайн, перепроверка раз в N дней.
- Платные функции — только за `Entitlements`; тест: без права облачные функции выключены, локальные работают всегда.
- Облачные вызовы (синк, ИИ) — только после проверки права на Worker; иначе дорогие запросы может слать кто угодно.

## 4. Расходы на инфраструктуру (владелец 2026-11-23: сначала хотя бы отбить их; ~$200 на подписки Claude — уже потрачено, возврат разработки — позже)
Цены по справкам сервисов **[сверить перед решением]**: Firestore $0,03 за 100 тыс. чтений и $0,09 за 100 тыс. записей сверх бесплатных 50 тыс./20 тыс. в сутки (нужен план Blaze, минимального платежа нет); Cloudflare Workers — бесплатно 100 тыс. запросов/сутки, платный план от $5/мес (KV: бесплатно 1000 записей/сутки); Claude Haiku 5.5 — $0,10 / $0,50 за млн токенов (вход/выход).
| Статья | Сейчас | Платная, когда | Оценка |
|---|---|---|---|
| Play Console | — | сразу | $25 разово |
| Firestore | 0 | чтений > 50 тыс./сут на весь проект | на «семью» с опросом раз в минуту ≈ 86 тыс. чтений/мес ≈ $0,03/мес; с пушами ≈ $0,003 |

| Облачный разбор заметки | ~$5 баланса | с первой заметки | ≈ 500 токенов на входе и 200 на выходе ≈ $0,00015; 50 заметок/мес ≈ $0,01 |
| GitHub Actions | 0 | > 2000 мин/мес (приватный репо) | $0,008/мин Linux; ПР ~6 мин ≈ $0,05 |
| Домен для страницы политики | 0 (GitHub Pages) | по желанию | ~$10–12/год |
- **Итого постоянные расходы при росте ≈ $8/мес** ($5 Worker + $25/12 Play за первый год + запас), переменные ≈ $0,04/мес на платящую семью. Бесплатные пользователи облаком не пользуются (синк и ИИ платные) — расхода на них нет.
- Риск: Firestore без жёсткого лимита — злоупотребление или баг = счёт. Нужны бюджетное оповещение, правила и App Check; облачные вызовы только после проверки права (§3).
