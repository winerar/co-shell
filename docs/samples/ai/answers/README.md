# Ответы моделей, записанные на телефоне (#742)

Замер `tools/aibench` («Поделиться ответами модели») даёт по файлу на модель и вычислитель: `<модель>-<cpu|gpu>.json` —
каждый запрос приложения к модели, её ответ и итог прогона (`scores`). Положить файл сюда — и `AiEvalTest` (`core:data`, jvmTest)
прогоняет те же ответы через код приложения в каждом `check`: итог не может стать ниже `scores` файла (это нижняя планка; код стал читать лучше — поднять `scores` до нового итога).
Изменили сам запрос (текст для модели) — записи не совпадут: тест скажет «запишите заново» и пропустит файл.
