# Навигация и жесты

> Часть дизайн-системы ([design-system.md](design-system.md)). Решения владельца о том, как устроено управление.

Решение владельца 2026-11-09: «удобно одной рукой, большим пальцем» (решение владельца 2026-11-09: «удобно одной рукой, большим пальцем»)
- **Нижняя панель:** Обзор · Операции · [+] · Отчёты · Ещё (#140; «Счета» — «Ещё → Деньги» и «Все счета ›» на «Обзоре») (`CoShellBottomBar`, вкладки — `navigation/MainBottomBar`); «+» — новая
  операция с любой вкладки. Вид — как в макетах (`docs/design/`): плавающая капсула 56 dp в 32 dp от краёв (`Sizes.bottomBarHeight`, `panelInset`; опрос #441 Б),
  фон `surfaceContainerHigh`, вкладки — иконки без подписей (подпись — `contentDescription`), пилюля 40 dp на
  всю ячейку, «+» 48 dp (все кнопки 48). Своих FAB «новая операция» на экранах нет. Внутри панели — **без `fillMaxHeight`/`fillMaxSize`**:
  панель растянется на весь экран, экраны станут высотой 0 (баг релизов #52/#56; ловит `MainShellSmokeTest`).
  Вне вкладок панель не исчезает, а уезжает вниз (`visible = false`), место под ней закрывается той же пружиной.
- **Телефоны с кнопками навигации внизу** (три/две кнопки вместо жестов; узнаём по `WindowInsets.tappableElement`, `components/SystemNavigation.kt`):
  серой системной подложки нет (`clearNavigationScrim` — окно активности и окно шторки), полоса под кнопками — цвет фона (`CoShellNavButtonsBackdrop`
  в `MainShell`): списки не уходят под кнопки; капсулы (`CoShellBottomBar`, `CoShellActionBar`) стоят на `Spacing.s` выше полосы, а не на `Spacing.l`
  (`capsuleBottomGap`). Новое, что лежит у нижнего края, — проверять на обоих видах навигации.
- **Назад** — системный жест с предпросмотром (`enableOnBackInvokedCallback`). В редакторах стрелки нет;
  стрелка вверху осталась только на справочных экранах (курсы, категории, настройки) — запасной путь.
- **Редакторы (операция, счёт, категория) — шторки снизу:** `dialog<…>` destination с `CoShellSheetDialogProperties`
  + `CoShellSheet` (свайп вниз, тап мимо, жест «назад» закрывают); внутри `ui/sheet/EditSheetLayout` (обёртка
  `CoShellSheetLayout` со строкой «Сохранить») — заголовок, форма,
  «Сохранить» закреплена внизу на всю ширину над клавиатурой. Новый редактор — так же. Исключение — **шторка
  ввода операции** (#505, один шаг, 2026-11-18): тип (Расход · Доход · Перевод) + ☰ «Шаблоны» → **лента значков счетов**
  (`CoShellAccountRibbon`: последний использованный выбран, «Все ›» — полный список `AccountPicker`, выбор возвращает в шторку;
  у перевода две ленты «Откуда» и «Куда») → карточки «Сумма», «Категория», «Детали» → клавиатура с «Готово». Правка операции — та же шторка; у сохранённой тип («Расход · Доход · Перевод») — в верхней строке рядом с «Дублировать» и «Удалить» (#509, опрос «А»).
- **Свайпов по строкам нет** (#112, 19В). Горизонтальный свайп листает вкладки (`navigation/TabSwipe`: порог
  `Sizes.tabSwipe`, экран наклоняется на ¼ пути, пилюля нижней панели едет за пальцем (`TabDrag`, опрос 2026-11-16); ряды, листающиеся вбок, побеждают). **Удержание строки
  операции** — режим выбора: шапка «✕ Выбрано N», панель «Дублировать» (только одна) · «Удалить · N»; «Назад»/«✕» — выход.
- **Дублировать** — из режима выбора или кнопкой в шторке операции: шторка с копией на сегодня, метка
  «Копия · сегодня» (`TransactionEditDestination(copyFrom)`).
- **Удаление операции** — из режима выбора или кнопкой в шторке, сразу, без «Вы уверены?»; плашка
  «Операция удалена» / «Удалено операций: N» · «Отменить» (`undo/UndoCenter` → снэкбар в `CoShellNavHost`). Счета и категории —
  пока с подтверждением (их удаление блокируется, если они используются).
- **Шапки** (`ui/top/`, подробно — `components-topbars.md`): вкладки — `TabTopBar` в одну строку: **узкая парящая капсула 56 dp, 32 dp от краёв, как нижняя панель** (опрос 2026-11-16 #441 Б; без подложки за ней, тонкая обводка — `fillEdge`, где заливка сливается с фоном; заголовок 22 sp, не сжимается, без линии; поиск — лупа в шапке, #394 Б), выбор — `TabOrSelectionTopBar`; внутренние
  экраны — `ScreenTopBar` в той же капсуле («Назад» — шеврон без подложки + `titleLarge` 22 sp Bold, вторая строка по желанию). Свою `TopAppBar` в экранах не собирать.
- **«Ещё»** (опрос 2026-11-20, Б; доски `More`, `MoreB*`) — четыре группы строк `CoShellMenuRow`: Деньги (Счета, Категории, Бюджеты, Регулярные, Быстрые заметки, Черновики со счётчиком) ·
  Валюты (Курсы, Конвертер) · Семья и данные (Семья, Резервная копия, Импорт, Экспорт) · Приложение (Настройки, Отзыв). Версия — тихая строка внизу,
  карточка `VersionCard` сверху — только когда вышло обновление. Настройки (тема, подсказки, валюты итогов…) — «Ещё → Настройки», не строками «Ещё»;
  «Стереть все данные» — внизу «Резервной копии». Сумма в шторке — своя клавиатура (`CoShellKeypad`).
