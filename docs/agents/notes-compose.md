# Заметки агента: Compose и Material 3

Грабли Compose, Material 3 и компилятора Compose, найденные в работе (вынесено из `notes.md`).
Формат тот же: `- (дата) факт — что из этого следует`.

- (11-23, #624) Свой хост снэкбара вместо Material `SnackbarHost` должен **сам** вызывать `dismiss()` по таймеру: тайм-аут живёт в `SnackbarHost`, а `showSnackbar` ждёт вечно (`CoShellSnackbarHost`, `SnackbarTimeoutTest`).
- (11-23, #640) Внешний `Scaffold` с нижней панелью отдаёт `bottom = 0`, когда панель уехала (внутренние экраны): полосу системных кнопок никто не вычитает — кнопке внизу нужен `navigationBarsPadding` (`aboveBottomBars()`).
- (11-12) Compose `lerp(Color, Color, t)` смешивает в **Oklab**, не в sRGB — подбирать цвета/контраст заранее скриптом с Oklab (как в #249), иначе числа не сойдутся с `ColorContrastTest`. (11-13, #271) Тёмный герой — узкое место новых палитр: яркий `primary` (Лимон) валит подсказку → темнее `backgroundDark`.
- (11-10) `Modifier.drawBehind` на `NavigationBar`/`Surface` рисует **под** их фоном — фон закрасит рисунок.
  Фон ставить своим `background()` перед `drawBehind`, а `containerColor = Transparent` (так пилюля вкладки).
- (11-09) `rememberGraphicsLayer().record{}` хранит ссылки на слои детей, а не их копию — снимок «старого» кадра
  делать сразу `toImageBitmap()` до смены (так `motion/ThemeReveal.kt`), иначе дети перерисуются уже новыми.
- (11-09) `MaterialTheme(motionScheme = …)` и интерфейс `MotionScheme` в material3 **1.4.0 закрыты** (`internal`),
  в `1.5.0-rc01` открыты — поэтому версия material3 закреплена в `libs.versions.toml`; при выходе стабильной 1.5 — перейти на неё.
- (11-09) Пересечение касаний в Compose: родительский `detectTapGestures` получает тап по ребёнку, если тот не
  поглотил событие (`Surface` без `onClick` не поглощает) — скрим шторки сделан **соседом** под ней, а не родителем.
- (11-09) `AnimatedVisibility` внутри колонки с `spacedBy`: зазор появляется/исчезает рывком вместе с ребёнком —
  отступ класть внутрь раскрывашки, а её — в колонку, где всегда что-то видно (так в форме операции).
- (11-09) Lint `UnusedContentLambdaTargetStateParameter`: в `AnimatedContent` рисовать из параметра лямбды, а не из
  внешнего состояния; ключ анимации — `contentKey` (иначе уходящий кадр показывает уже новое состояние).
- (11-09) M3 красит `primary` и как заливку, и как текст (`TextButton`, фокус поля, `Tab`, «сегодня» в `DatePicker`).
  При светлом неоновом `primary` текстовые места переопределять на `accentInk()`, иначе текст исчезает на белом.
- (11-14) Robolectric снимает `Popup` (второй корень `onAllNodes(isRoot())[1]`) **чёрным** — для эталона/сверки выносить содержимое попапа в отдельную функцию (так `PeekCard`). Долгое нажатие в UI-тесте: `performTouchInput { down(center) }` + `mainClock.advanceTimeBy(1000)` (`advanceEventTime` таймаут жеста не двигает).
- (11-15, #383) Отчёты компилятора Compose (`reportsDestination`) кэш сборки **не восстанавливает**: `compileDebugKotlin FROM-CACHE` — папки отчётов нет. Поэтому проверка — `agent.sh stability` с `--rerun`, не тест в `check`. Без `compose-stability.conf` нестабильны все `LocalDate`/`YearMonth` и классы `core:model` (модуль без компилятора Compose); рекурсивный класс (`children: List<Сам себя>`) — только `@Immutable`.
- (11-16) `Modifier.border(w).padding(p)` — рамка рисуется **внутри** коробки: зазор до содержимого = `p − w` (при `p == w` кольцо лежит на краю). Кольцо вокруг скруглённой плитки: отступ `w + gap`, радиус `R + w + gap` (`CoShellPaletteSwatch`).
- (11-16) `Row` меряет невзвешенных детей **первыми**: длинный `trailing`/итог съедает место, а взвешенный текст рядом ломается по букве в столбик. Лечение: потолок ширины (`CoShellListRow` — 60 % под `trailing`), `FlowRow` для «заголовок + итог», своя раскладка для пилюль (`RowTags`, `fitWidths`). Ловится стресс-эталоном `transactions_stress_*` (320 dp, шрифт ×1,3).
- (11-16, #432) `Row`: элементы без `weight` меряются **по порядку** и раньше взвешенных — длинный текст суммы забирает всю ширину, а кнопка после него получает 0 и уезжает под текст. Кнопку — мерить первой (свой `Layout`, как `NameAndAmount`), сумме — потолок.
- (11-16, #433) `TextAutoSize.StepBased` при нехватке места на `minFontSize` **обрезает** текст; для денег — `fitAmountAutoSize` (ужимает ниже минимума, пол 4 sp). `TextAutoSize` — публичный интерфейс, свой класс должен иметь `equals`/`hashCode` (data class).
- (11-16, #439) Тело `CoShellModalSheet` — колонка с `spacedBy(Spacing.m)` (12 dp): строки списка прямо в ней получают лишний промежуток («большие межстрочные») — список класть в свою `Column {}` (так `ChoiceRows`). В Roborazzi у тест-колонки свой `spacedBy(Spacing.l)` — шаг строк в эталоне мерить с поправкой.

## Переезд на компоненты (#367, 2026-11-16)
- Нарушение правила, которое нечем заменить, почти всегда лечится существующим: метка → `CoShellStatusChip` (+ тон), круг-значок → `IconBadge`, цветные кнопки → `coShellButtonColors(container, content)`, круглое нажатие → `tactileCircleClickable`, размеры значков → токены `Sizes`. Новый компонент — только после опроса и карточки на доске (`ApprovedComponentsTest` ищет **имя** в `mockup_catalog*.py`).
- Предложения до «ок» — отдельный модуль `mockup_comp_*.py` + `poll-*.json`; после ответа победитель идёт в `mockup_catalog_*`, доски предложений убрать из `gen-mockups.py` и с холста.
- Скрипт «убрать неиспользуемые импорты» не должен трогать `getValue`/`setValue` (делегаты `by`) — иначе «has no method getValue».
- Холодный `app:transformDebugClassesWithAsm` может упасть «Cannot load class Hilt_…»: `rm -rf app/build` и `--no-build-cache`.
- После правки экрана эталоны: `agent.sh shots '*ScreenshotTest*'`, затем посмотреть PNG; текст в коде запрещён даже в `+N` только если это буквы (цифры и знаки можно).
- (11-16, #445) Строка «название + метка + сумма» (`CoShellBarRow`): `Row` с весом у названия сжимает его до «Ко…». Своя раскладка `LabelAndValue`: названию — минимум 96 dp, не остаётся — сумма с меткой уходит второй строкой под название (вправо); внутри — `FlowRow(itemVerticalAlignment = CenterVertically)` (без него сумма встаёт выше метки). Код валюты у итога — `softWrap = false` в `FlowRow`, шапка периода — до 2 строк.
- (11-16, #378) Строки из `dp`-кружков (`ColorStrip`) на 320 dp × 1,3: «+17» после 8 кружков получает остаток ширины и ломается столбиком — число кружков считаем от ширины (`BoxWithConstraints`, резерв под «+N» растёт с `fontScale`). Сумма в плитке формы (`CoShellDetailTile(amount = true)`) ужимается `fitAmountAutoSize`, а не «99999…».
- (11-16, #378) Шторка ввода на 320 dp × 1,3: шапка и строка «Чек» — `FlowRow` (слово «Расход», валюта чека, курс и «✕» уходят второй строкой целиком). Вес `weight(1f, fill = false)` рядом с `Spacer(weight(1f))` делит остаток пополам — чип резало вдвое; для «уступить место» нужен именно `FlowRow`. Курс у чека раньше обрезался («1 USDT = 1 015,27» без «ARS») и на 393 dp — теперь второй строкой.
- (11-16, #378) Клавиатура: подпись «Провести» на кнопке «Готово» ужимается `fitAmountAutoSize` (иначе «Прове/сти» на 320 dp × 1,3). `CoShellFormSection`: между заголовком и ссылкой справа — зазор `Spacing.s`. «Регулярные платежи»: название — до 2 строк (рядом с широкой суммой было «Платё…»).
- (11-16, #454) `CoShellListRow` — свой `Layout` вместо `Row` с потолком 60 %: сумма справа остаётся рядом, пока тексту хватает `120 dp × fontScale`, иначе уходит под текст (вправо) — слова не рвутся в столбик. Эталоны почти всех списков сдвинулись на субпиксель (цвета те же).
- (11-16, #455) Диалог (`CoShellConfirmCard`): две кнопки рядом, пока каждой хватает `140 dp × fontScale`, иначе друг под другом (главная сверху); высота — по подписи (`IntrinsicSize.Min`), не фиксированные 48 dp. Двух кнопок в `Row` без весов в приложении нет.
- (11-16, #379) Строка «заголовок + подпись справа» на узком экране/шрифте ×2: `Row` с весом у заголовка ломал слова («На / что / ушл / и»). Шаблон — `FlowRow` (заголовок целиком, подпись с `weight(1f)` и `TextAlign.End` уходит под него): `SpendingCard`, `BudgetSummaryCard`. Шапка периода «‹ Ноябрь 2026 › USD» ниже `Sizes.narrowRow × fontScale` — пилюля валюты под месяцем. Суммы вне списков (`AccountPreviewCard`) и «Todas 52» в `IconStrip` — `fitAmountAutoSize`. Эталоны: `*_stress_es_narrow_light` (es, 320 dp, ×1,3) и `*_stress_x2_narrow_dark` (ru, 320 dp, ×2,0), `ScreensLocaleStressScreenshotTest`.
- (11-16, #379) Сумма во фразе («потрачено X из Y», прогноз, подписи конвертов) — через `breakableBeforeCurrency()` (`ui/format/SentenceAmount.kt`): `MoneyFormat` склеивает «число USD» неразрывным пробелом, и при 320 dp × 2,0 это слово шире строки — движок рвал код валюты («US/D»). Отдельная сумма (`AmountText`) остаётся склеенной.
- (11-20) Окно-карточка (`Dialog` + `Column`) без прокрутки: не влезло по высоте — последний ребёнок (кнопка) получает остаток и сжимается в полоску («Понятно» в «Обновлено до N»). Тело — `Column(Modifier.weight(1f, fill = false).verticalScroll(…))`, кнопка под ним; стресс — `UpdatedCardStressScreenshotTest`, `ConfirmCardOverflowTest` (проверяют высоту кнопки ≥ `Sizes.button`).
- (11-20, #145) Шторки и диалоги (`dialog<…>`, `Dialog`) — **отдельные окна** над окном активности: композабл «поверх всего» (экран PIN) их не закрывает. Скрыть приложение целиком — убрать его из композиции, состояние сохранить `rememberSaveableStateHolder` (`PrivacyHost`; стек навигации и ViewModel шторки возвращаются, `PrivacyHostTest`).
- (11-23, #379) «Черновики» на es ×1,3 / 320 dp: `Row` с `weight(1f)` у названия оставлял «К…» рядом с суммой. Строка «название + сумма» — `FlowRow` (название целиком, сумма в `Box(weight(1f), CenterEnd)` уходит под него); находит стресс-эталон `drafts_stress_*` (`ScreensLocaleStressScreenshotTest`: заметки и черновики добавлены).
- (11-26, #730) `ChoiceSheet` после выбора вызывает только `onPick`, **не** `onDismiss`: `onPick` сам сбрасывает флаг показа. Конвертер этого не делал — окно выбора валюты оставалось поверх и съедало клавиши. Новый вызов — с тестом «выбрал → окно закрыто» (`ConverterSheetTest`, `AllCategoriesSheetTest`).
