# Модели ИИ на телефоне: что есть, где пригодятся, стоит ли (2026-11-20)

Исследование по просьбе владельца. Отчёт и опрос: https://claude.ai/artifact/1pWrsJHxXR6FNPTndv8Kc3 (ответы — `ArtifactData list`, коллекция `answers`). Факты на ноябрь 2026, источники внизу.

## Коротко
- **Готовые «умные» функции почти все делаются без модели ИИ**: категория по получателю, разбор голосовой фразы,
  итоги месяца — обычная логика на Kotlin, работает на любом телефоне, весит 0 КБ, проверяется тестами.
- **Встроенный ИИ телефона (Gemini Nano)** бесплатен и не увеличивает APK, но есть только на флагманах 2024+
  (Pixel 9–11, Galaxy S25/S26, Xiaomi 15/17, OnePlus 13/15). **Xiaomi 13 (2211133C) в списке нет.**
- **Своя скачиваемая модель (Gemma и аналоги)** — 0,5–2,6 ГБ загрузки и 1–2 ГБ памяти при работе: ломает бюджеты
  «лёгкое приложение» (`performance.md`: APK < 15 МБ, память < 150 МБ). Для семейного бюджета не окупается.
- **Рекомендация:** сначала «умная категория» без ИИ; голосовой ввод — системным распознаванием речи; Gemini Nano —
  только как необязательное дополнение там, где телефон его умеет (чеки, которые не узнал ни один формат).

## Что есть (ноябрь 2026)
| Что | Размер для нас | Телефоны | Плюсы | Минусы |
|---|---|---|---|---|
| **Gemini Nano** через ML Kit GenAI (AICore): свой запрос (Prompt API, в т. ч. картинка → JSON), пересказ, правка текста, описание картинки, распознавание речи | ~0 (модель в системе) | Pixel 9–11, Galaxy S25/S26, Xiaomi 15/17, OnePlus 13/15 | бесплатно, офлайн, данные не уходят с телефона | нет на большинстве телефонов (и на Xiaomi 13); только когда приложение на экране; квоты; только Android |
| **Gemma** через LiteRT-LM (Google AI Edge): Gemma 3 1B, Gemma 3n, Gemma 4 E2B (текст + картинка + звук) | библиотека ~несколько МБ + модель 0,53 ГБ (3 1B) … 2,58 ГБ (4 E2B) загрузкой | любой с 4–8 ГБ ОЗУ | работает на любом современном телефоне | ~1,7 ГБ памяти при работе, батарея, где хранить модель (GitHub Releases ≤ 2 ГБ на файл), лицензия Gemma |
| Другие малые LLM (Qwen 3 0,6–1,7B, Llama 3.2 1B, SmolLM) через llama.cpp / ExecuTorch | то же | то же | открытые лицензии | то же + своя нативная сборка |
| **ML Kit без генерации**: распознавание текста на фото (OCR) | ~260 КБ (модель через Google Play services) | почти все с Play services | дёшево | **только латиница** — испанский чек да, русский скриншот (Т-Банк) нет |
| ML Kit: поиск сумм, дат, адресов в тексте (Entity Extraction) | ~5 МБ на язык загрузкой | почти все | ru/es/en (проверить на телефоне) | наш `AmountInText` уже делает это для чеков |
| Распознавание речи: системный `SpeechRecognizer` (на устройстве, Android 12+) | 0 | зависит от прошивки | бесплатно, ru/es/en обычно есть | у части прошивок Xiaomi сервиса нет/только онлайн — проверять `checkRecognitionSupport` |
| **Своя логика без ИИ** (частоты, правила) в `core:domain` | 0 | все + будущий iPhone (KMP) | объяснимо, тестируемо, мгновенно | не «понимает» новые формулировки |

Облачный ИИ (Gemini API, Claude и др.) не рассматриваем: данные бюджета ушли бы на чужой сервер, нужен ключ в APK, бесплатные тарифы меняются — против «бесплатно и надёжно, без своих серверов» (`owner.md`).

## Почему не скачиваемая модель
- Бюджеты `performance.md`: APK < 15 МБ (ML Kit-сканер штрихкодов уже не прошёл, ROADMAP), память < 150 МБ — модель берёт 1–2 ГБ.
- Загрузка 0,5–2,6 ГБ на каждый телефон, место, батарея; ответ — секунды, а ввод операции должен быть мгновенным.
- Для задач А–В модель не нужна, для Г хватает системного Gemini Nano там, где он есть.
- Вернуться, если: на телефонах семьи появится Gemini Nano (тогда Г дёшев), или семья захочет фото бумажных чеков (Д).

## План, если владелец согласен
1. «Умная категория» (А + Б): чистая логика в `core:domain` + подпись «по прошлым операциям» в шторке; макет → опрос → код.
2. Голосовой ввод (В): проверка `SpeechRecognizer` на телефонах семьи, разбор фразы, макет кнопки микрофона.
3. Эксперимент Г — только если телефон поддерживает Gemini Nano (проверка `checkFeatureStatus`), за интерфейсом в `core:domain`, без него всё работает как сейчас.

## Дополнительное исследование (2026-11-20, вечер) → уточняющий опрос https://claude.ai/artifact/C3R4S6oezFPBBKoE8SJixL
- **Голос (#585):** ML Kit GenAI Speech Recognition, «базовый» режим — офлайн на большинстве Android 12+, ru-RU и es-ES в бете
  (Advanced — только Pixel 10); не зависит от системного сервиса распознавания прошивки (у части Xiaomi его нет). Проверить на телефонах.

  Qwen 3.5 0,8B — ~95 % F1 в извлечении продавца из банковских операций после LoRA-дообучения (arXiv 2606.08051).
  Без дообучения малые модели ненадёжны → эталон ~100 примеров на ru/es/en и порог точности перед включением.
- **Лицензии:** Gemma 4, Qwen — Apache 2.0; Gemma 3/FunctionGemma — Gemma Terms (распространение с файлом-уведомлением и
  передачей ограничений). Размер библиотеки LiteRT-LM в APK не найден — замерить в прототипе.
- **Умная категория (#584):** в YNAB/Monarch/Wallet это правила «получатель → категория», не ИИ; у нас правила берутся из истории.
