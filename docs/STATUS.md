## Где мы
- Модули: `app`, `core:model`, `core:domain`, `core:data`, `core:designsystem` (структура — `docs/agents/project-structure.md`).
- `core:domain`: `SaveTransactionUseCase`, `SaveAccountUseCase` (валюта счёта с операциями заблокирована),
  `SaveCategoryUseCase` / `ArchiveCategoryUseCase` (папки: один уровень, тип папки = тип подкатегорий),
  `DeleteAccount/CategoryUseCase` (используемое не удаляется — только архив), `SeedDefaultCategoriesUseCase`.
- `core:model`/`core:domain` курсы: `Rate` (точный курс), `ExchangeRate`, `rates/RateBook` + `CurrencyConverter`
  (правила поиска — `money-and-currency.md`); загрузка — `RatesProvider` перебирает источники
  (`core:data/rates/`: currency-api через jsDelivr → то же через Cloudflare → open.er-api, только последний курс).
  Хранение — `ExchangeRateRepository` (`RoomExchangeRateRepository`): ручные курсы (синк, бэкап) и
  загруженные (кэш), `usedCurrencies()` + `RatesSnapshot.keepOnly` (`database.md` §«Курсы»).
  Фоновая загрузка — `RefreshRatesUseCase` + `app/.../rates/work/RatesRefreshWorker` (раз в сутки при сети,
  планируется при запуске приложения; история — дни операций без курса, ≤ 30 за запуск; ARCHITECTURE §6).
  Живьём API не проверялись (песочница их блокирует) — формат ответов из документации; проверить на
  телефоне: после первого запуска с сетью в «Чек в другой валюте» должна появиться подстановка «списано».
- `core:data`: Room (схема v3: автомиграции 1→2, 2→3 с тестами `MigrationTest`), мягкое удаление, баланс SQL-агрегатом, JSON-бэкап (с ручными курсами). Правила — `docs/agents/database.md`.
- `app`: навигация (type-safe routes, `navigation/`) с нижней панелью **Обзор · Операции · Счета · Ещё**.
  - Счета: список с балансами и архивом, редактор (название, валюта с подсказками, тип, начальный баланс,
    «Учитывать в общем балансе»), архив/удаление. Исключённый счёт — пометка «не в общем балансе» в списках.
  - Ещё → Категории: вкладки Расходы/Доходы, раскрывающиеся папки, «Новая папка» (отметить категории внутрь),
    «Добавить в папку», редактор (название, тип, иконка, цвет, папка), архив/удаление.
    Значок категории (иконка в круге её цвета) — в списке категорий, в списке операций и в чипах
    выбора категории при вводе операции (общий компонент `CategoryBadge`, 38 иконок, 18 цветов).
  - Ввод операции (`transactions/edit/` — образец структуры экрана): Расход/Доход/Перевод, сумма,
    счёт (по умолчанию — последний использованный), категории с папками, дата (Сегодня/Вчера/DatePicker),
    заметка; перевод между валютами — вторая сумма. «Чек в другой валюте» (расход/доход): валюта и сумма
    чека + «списано со счёта», подсказка «Курс покупки: 1 USD = 1 049,69 ARS»; в списке — сумма чека
    под суммой операции (`ReceiptForm.kt`, `components/ReceiptSection.kt`). «Списано» подставляется по курсу
    из суммы чека, пока его не правили руками (`DebitSuggestion.kt`, подпись «По курсу на … — поправьте по выписке»).
    **Не проверено на телефоне.** Редактирование и удаление (маршрут с `transactionId`).
    Вход — FAB на «Обзоре» (если есть счета) и «Операциях».
  - «Операции» (`transactions/list/`): список по дням (липкие заголовки «Сегодня/Вчера/дата»), категория,
    счёт · заметка, сумма цветом; у перевода «A → B» и вторая сумма между валютами. Тап — редактор.
    Грузится весь список сразу — при импорте Wallet (тысячи строк) понадобится пагинация.
  - Ещё → Курсы валют (`rates/list/`): курсы используемых валют к USD на сегодня (дата, «вручную»,
    «через USD»), дата и источник последней загрузки, «Обновить сейчас» (разовый запуск воркера,
    `rates/work/WorkManagerRatesRefresher`), ручные курсы (добавить / тап — изменить / корзина — удалить;
    тап по курсу на сегодня — задать его вручную), ссылка-атрибуция ExchangeRate-API. **Не проверено на телефоне.**
  - Ещё → Валюты отчётов (`currencies/list/`): список (первая — основная, по умолчанию USD), тап — сделать
    основной, добавить (подсказки — используемые валюты), удалить (кроме последней). Хранится на телефоне
    (`PrefsReportCurrencySettings`), в этапе 4 — в настройки семьи. Экран «Курсы» считает от основной валюты.
  - «Обзор» (`home/`): общий баланс неархивных счетов в каждой валюте отчётов (основная крупно) по курсу на
    сегодня (`core:domain/rates/BalanceTotals.kt`), «По курсу на …», «Без учёта: RUB — нет курса»,
    тап — суммы по валютам счетов; счета «не в общем балансе» не входят. Ниже — «Траты за <месяц>» в валютах отчётов (`rates/MonthSpending.kt`:
    только расходы, сумма списания, каждая — по курсу на её день; `home/components/SpendingCard.kt`).
    **Не проверено на телефоне.**
  - Ещё → Обновление приложения (`update/`): версия, проверка, «Скачать и установить» с прогрессом,
    запрос разрешения на установку; при запуске — диалоги «Доступна версия…» и «Что нового» (`update/startup/`).
    «Доступна версия…» — при каждом запуске, пока не установлена (найденная версия запоминается, сеть ≤ раз в час).
  - Ещё → Резервная копия (`backup/`): «Сохранить копию» (системный диалог «Сохранить как»,
    имя `co-shell-<дата>.json`) и «Восстановить из копии» (выбор файла → подтверждение → итог).
  - Встряхивание → ввод операции (`shake/`, `core:domain/shake/ShakeDetector`): только на вкладках
    нижней панели и пока приложение на экране; короткая вибрация; выключатель «Ещё → Встряхнуть — новая
