# Доска задач: токен для автоматики

Доска https://github.com/users/winerar/projects/4 сама заполняется из задач репозитория — Action
**Tasks** (`.github/workflows/tasks.yml`). Ему нужен ваш токен: стандартный токен Actions не видит
проекты пользователя. Как устроено — `docs/agents/tasks.md`.

## 1. Создать токен (classic)
1. GitHub → аватар → **Settings** → **Developer settings** → **Personal access tokens** → **Tokens (classic)**
   → **Generate new token (classic)**.
2. Note: `co-shell board`. Expiration: 1 год (поставьте напоминание в календарь).
3. Права (scopes): **`project`** и **`repo`** (`repo` нужен, чтобы добавлять задачи приватного репозитория на доску).
4. **Generate token** → скопировать (показывается один раз).

## 2. Сохранить в репозитории
`co-shell` → **Settings** → **Secrets and variables** → **Actions** → **New repository secret**:
имя **`PROJECT_TOKEN`**, значение — токен.

## 3. Проверить
**Actions** → **Tasks** → **Run workflow**. Через минуту на доске:
колонки Разобрать · Бэклог · Очередь · В работе · Ждёт владельца · Готово, в них все открытые задачи.
Прежние колонки (Todo/In Progress/Done) заменяются этими — это нормально.

## Как пользоваться
- Перетаскивайте карточки: метка задачи поменяется сама (в течение 3 часов). «Готово» — закрывает задачу.
- Вопросы к вам — колонка **Ждёт владельца**: ответ комментарием в задаче.
- Новые отзывы из приложения появляются в **Разобрать**.
